🔑 Éléments Clés

  • ChronoKraft.Domain (vert) : aucune dépendance à EF Core/ASP.NET — testable en millisecondes avec xUnit, sans base de données
  • Système de Pointage Externe (orange) : source de vérité pour le total d'heures, jamais pour la ventilation par rôle
📄 ADR-0002, ADR-0003

🔑 Bénéfices Concrets

  • Vérifié à la compilation : ChronoKraft.Domain ne peut référencer EF Core — toute violation casse le build
  • Extensible sans modification : ajouter un type de dépendance Gantt = ajouter une classe IDependencyStrategy
  • TDD réaliste : ChronoKraft.Domain.Tests s'exécute sans PostgreSQL
📄 ADR-0003

🔐 Authentification et Rôles

Quatre rôles : Admin, Manager, Contractor, Worker. Trois d'entre eux se lient à une entité métier existante via une FK optionnelle ; Admin n'a aucun profil métier associé.

🔑 Règles

  • Le système ne détermine jamais automatiquement le rôle
  • Une divergence est toujours acceptée, jamais bloquante
  • Toute divergence est toujours tracée via TimesheetReview
